# Plans for the demo

The phased plans still open that the finished demo needs. Open work is listed in `docs/BACKLOG.md`. When a plan's last phase
ships, its "As built" note goes at its end and it moves to `docs/archive/`. Ideas kept for after the demo are in `docs/post-demo/`.

| Plan | What it covers |
|---|---|
| [`COMPANY.md`](COMPANY.md) | The company as people (C1-C8): faces, natures, ties, gear as things; the camp, named men in the fight, what is remembered |
| [`HOLDS.md`](HOLDS.md) | Castles by size, promotion anywhere, the castle's muster, villages bound to a holder (HD1-HD7) |
| [`NOBILITY.md`](NOBILITY.md) | Common and noble troop trees, esquires, knighting a named man (N1-N5) |
| [`PLAYTEST.md`](PLAYTEST.md) | Fixes from playtests (PT1-PT6) |
| [`SETTLEMENTS.md`](SETTLEMENTS.md) | Towns, castles, villages and the siege field by people (SM1-SM7) |
| [`THE_WILD.md`](THE_WILD.md) | Monsters as part of the game: wildness, growing lairs, spoils, new monsters, the world crisis (WI1-WI9) |
| [`WORLD_DRESS.md`](WORLD_DRESS.md) | The dressed map: cover, shores, roadsides, life, air and weather (WD1-WD7) |
