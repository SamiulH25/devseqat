# Archived sprint plans

These are the phase-by-phase plans the game was built from (each phase shipped on its own, with an "As built" note at the end).
They are kept for history and for the reasons behind the code; code comments still point into them by section.
Open work is listed in `docs/BACKLOG.md`. The living docs are `CLAUDE.md`, `docs/DEVELOPING.md`, `docs/DESIGN.md`, `docs/CAMPAIGN.md` and `README.md`.
